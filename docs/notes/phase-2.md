# Phase 2 Notes

## Relationship authorization is the security boundary

All mentor employee routes use the same access function. It requires a mentor role, an exact mentor-employee match, granted consent, active status, and no revocation timestamp.

## Verification and publication are different actions

A confirmed endorsement records a mentor's observation and support level. It does not publish the employee's ability. Mentor and AI suggestions stay drafts so a future employee workflow can accept or publish them.

## Moderation preserves attribution

Evidence and caption reviews store the reviewer and time, and every decision appends an audit entry. Caption approval requires human-reviewed text because generated captions may misrepresent atypical speech.
